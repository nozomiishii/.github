## 概要

ものづくりが好きです。作ったプロダクトでだれかの生活が豊かになったり、遊んでもらえたりしたら幸せです。アイデアの発想から実装、ユーザーに届けるまでの全てを楽しみながら開発しています。

フロントエンドを軸に、バックエンドやモバイルも含めて、新規立ち上げから保守運用まで幅広いフェーズを経験してきました。チームリーダーとして、進捗管理・コードレビュー・技術指導を担った経験もあります。

得意なのは、仕組みで品質を守る開発環境づくりです。ドキュメントは想定より読まれない、人為的なミスは避けられない、という実体験から、CI/CDやLint、コンポーネントテスト・E2Eテストの自動化を整備し、手動作業に頼らずに品質を保てる環境を設計してきました。過去のプロジェクトでは、4人が1日かけていた手動テストを30分の自動テストに置き換えています。

これからも、電子工学からプロダクトデザインまでコンピューターにまつわる領域を幅広く学びながら、ものづくりを続けていきます。

### 企業や自治体のCO2排出量の可視化や削減を支援するサービスプラットフォーム開発 (2024 年 5 月 〜)

#### 【担当業務】新規アプリケーション開発/開発環境構築/フロントエンド開発/現行機能の保守運用

- Next.js 16 App Routerを使用したアプリケーション開発
- Cursor、Claude Codeを活用したAI支援開発環境の設計・運用・チームへの展開
- ChromaticでのVRT、PlaywrightによるコンポーネントテストとE2Eテストの自動化
- 複数プロジェクトで横断的に利用する社内UIライブラリの開発
- OpenAPIを元にしたコードの自動生成
- React Server Componentsに対応したi18n環境の構築
- zxを使ったタスク自動化
- Sentryでの監視環境の構築

新規アプリケーションの設計・開発をフロントエンドの立場で主導しつつ、現行アプリケーションの保守運用も並行して担当しています。新規開発ではNext.js 16 App Routerを採用し、OpenAPIを起点としたコード自動生成でバックエンドチームとの並行開発を実現しました。
CursorやClaude Codeを開発プロセスに導入し、ルールファイルやプロンプトの設計と継続的なメンテナンスを通じて、AI支援開発の品質と再現性を担保する仕組みをチーム全体に展開しました。単体テスト・コンポーネントテスト・E2Eテストの3層で設計意図との整合性を検証し続けることで、AI生成コードを含めても堅牢さを保てる開発体制にしています。
このほか、React Server Componentsの制約を考慮したi18n基盤の設計、複数プロジェクトで横断的に使える社内UIライブラリの開発、Sentryによる監視体制の構築を担当しました。
